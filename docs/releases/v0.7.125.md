# Discordmaxxer v0.7.125

## Session migration reliability

This release prevents an update from treating Electron's empty session
folders as a valid login profile and skipping the real existing session.

## Highlights

- Session migration now checks for actual Chromium session contents instead of
  only checking whether marker directories exist.
- If an empty or cache-only stable session directory already exists, it is
  preserved as a `.pre-migration` backup and the real legacy session is moved
  into the stable Discordmaxxer location.
- Updating the client no longer unnecessarily sends users back to the Discord
  login screen when a recoverable legacy session is present.

Reset still intentionally logs the user out and clears the profile. This fix
only affects non-destructive migration during installation and startup.
