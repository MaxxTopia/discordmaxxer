# Discordmaxxer v0.7.153

## Highlights

This maintenance release keeps Rich Presence process scans out of visible
Windows console hosts. Rich Presence remains enabled, while the background
process lookup now uses the native Windows process API instead of launching
WMIC or another console utility.

## Fixed

- Fixed intermittent blank black Terminal/CMD windows appearing while
  Discordmaxxer was running with Rich Presence enabled.
- Kept the existing Rich Presence detection and activity behavior intact.
