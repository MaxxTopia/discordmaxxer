# Discordmaxxer v0.7.124

## Reset and update reliability

This release fixes two Windows reliability problems that could make the
client look like a different application or crash during reset.

## Highlights

- Reset confirmation now uses Discordmaxxer branding instead of the inherited
  Vesktop label.
- Reset cleanup is resilient to Windows file-lock and cache errors. A failed
  cleanup step is logged and does not become an unhandled main-process error.
- Development CSS hot reload now catches watcher start and `EPERM`/`ENOENT`
  errors instead of taking down the main process.
- Installed builds use one stable Chromium session directory across updates.
  A one-time, non-destructive migration can recover a session from the legacy
  DiscordmaxxerPortable, Vesktop, Vencord, or old profile locations when the
  stable profile is not present.

Reset still intentionally logs the user out and clears the profile. Updating
the app does not intentionally clear login data.
