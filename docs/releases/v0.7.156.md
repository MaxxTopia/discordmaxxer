# Discordmaxxer v0.7.156

## Highlights

This maintenance release fixes full-screen image viewing when Tournament Mode
is enabled.

## Fixed

- Keep Discord's native media-viewer entrance animation running in Tournament
  Mode so the image appears instead of leaving only the dark backdrop visible.
- Preserve the existing Tournament Mode performance safeguards for the rest of
  the renderer.
- Add a release-time regression check that keeps per-account rank badges tied
  to the viewed profile rather than leaking the current account's tier.

## Verification

The candidate passed the project test suite, strict Vencord overlay build,
artifact-integrity verification, and packaging checks. A signed-in image-viewer
click-through remains a user acceptance check after installation.
