# Discordmaxxer v0.7.97

## Highlights

- Fixed cross-PC profile rendering so stale settings from another account or install no longer override the shared owner roster. Banners, animated avatars, profile colors, and paid presentation choices now use shared owner state unless that field is actively being edited; saving or clearing returns the preview to shared state.
- Fixed profile widget skins so a viewer's local widget selection cannot paint another user's profile cards. Owner-published widget styles take priority, and cards remain native while the owner marker is unavailable.
- Shortened the client roster refresh window from one hour to five minutes so saved profile media, colors, and widget styles converge across PCs sooner without re-downloading media.
- Replaced the DM Hub's blank badge preview with the actual Discordmaxxer badge artwork.
- Reduced first-launch setup clutter by collapsing the full profile-gradient gallery behind an explicit "Show all" control while keeping the current choice visible and custom color controls available.
