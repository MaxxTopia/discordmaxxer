# Discordmaxxer v0.7.73

This update makes existing profile widgets recoverable after reinstalling, switching accounts, or losing local widget-editor state.

## What's changed

- The widget editor now reconciles the active Discord profile before deciding whether to show Create or Update.
- Existing attached widgets recover their application, configuration, hero asset, and selected skin identity when Discord returns partial profile data.
- Widget identity is stored per Discord account so Diggyai and DiggyT cannot silently load each other's local widget state.
- Selecting a skin applies it immediately in Discordmaxxer without republishing a card from an empty post-reinstall form.
- Updating an existing card is now explicit and is protected from publishing blank Valorant or Fortnite stats when private credentials are missing.
- The editor explains when Riot/Epic credentials must be re-entered; Discord never returns those private keys from a published widget.

## Visibility boundary

Widget skins are Discordmaxxer-client rendering features. They do not change Discord's native widget-v2 fields and are not guaranteed to appear in vanilla Discord.

An attached widget's published card remains on the owning Discord account. Copy/Import is still required when moving a widget between different Discord accounts.
