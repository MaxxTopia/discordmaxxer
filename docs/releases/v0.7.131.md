# Discordmaxxer v0.7.131

## Highlights

- Isolates the Spotify player and fallback surfaces from DMTrim promotional cleanup so the embedded player remains visible and interactive.
- Makes Spotify partial or unavailable track state fail safe instead of allowing malformed state to break the account panel.
- Adds a discoverable Voice & screen-share keybind shortcut through DMHub.
- Hardens the strict overlay pipeline and release verification around the native composer and message/image context-menu paths.

## Verification

- TypeScript and plugin-registry checks pass locally.
- Strict Vencord overlay and generated-bundle verification pass locally.
- The packaged Windows artifact and updater manifest are produced by the tagged release workflow.

## Release boundary

This release contains the source/build hardening above. Spotify playback and screen-share quality still require normal user-session acceptance on the target PC; no static build check can prove those live media paths by itself.
