# Discordmaxxer v0.7.76

This update makes widget skin choices recoverable across Discordmaxxer installs.

## What's changed

- Applying a skin to an existing widget now syncs a compact Discordmaxxer style marker to the owned widget application.
- A second Discordmaxxer install can recover that skin and layout automatically during widget attachment recovery or its periodic refresh.
- A deliberate local choice remains authoritative, so one install can intentionally use a different skin.
- Importing a widget code is treated as a deliberate local choice rather than being unexpectedly replaced by remote styling.
- The editor explains that this sync affects Discordmaxxer rendering only; it does not turn the skin into a native Discord widget field or guarantee vanilla Discord rendering.

## Visibility boundary

The published widget card and its live-stat data remain unchanged by the style marker. Apply the skin once on the source install, then reload or wait for the other Discordmaxxer install to recover it.
