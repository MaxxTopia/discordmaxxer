# Discordmaxxer v0.7.126

## Native message context-menu stability

This release removes DMEmoji's injection into Discord's native message context-menu route. That injection could destabilize ordinary message menus and leave Discord in crash recovery instead of showing the normal actions.

## Highlights

- Normal text and image message menus stay on Discord's native route, including Reply, Forward, reactions, Pin, Bookmark, Copy Message Link, and related actions.
- DMEmoji's composer picker, mouse-based Send button, and saved-media shelf remain available.
- The release preserves the existing profile flair, widget-skin, theme, tournament-mode, media, and optimization work already included in v0.7.125.
- The overlay is built with the strict rebrand and plugin-integrity checks enabled.

## Verification

- ESLint and TypeScript checks passed with `pnpm test`.
- The production build, strict Vencord overlay, staged-source verifier, and Windows packaging gates must pass before publication.
- A signed-in user should verify ordinary text and image message context menus, image opening, DMEmoji's composer controls, and the existing profile/plugin surfaces after updating.
