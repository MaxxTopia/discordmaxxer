# Discordmaxxer v0.7.151

## Highlights

- **Enable SpotifyControls by default:** the existing Vencord Spotify player is now included in the default-on plugin list. Its account-panel slot is inserted before Discord's account panel, and the existing previous, play/pause, skip-next, repeat, shuffle, and seek controls remain wired to Spotify's API.
- **Remove the MAXXER++ badge artifact:** removed the single explicit semi-transparent white arc that rendered above the minted `++` emblem. The gradients, minted geometry, sweep animation, glow, tooltip, finish selector, and error guards remain intact.
- **Keep the public theme-flair implementation:** the candidate is based on the verified v0.7.150 source, including the readable theme palette and opt-in flair path. The runtime check confirmed flair CSS is generated when enabled, then restored the saved profile settings.

## Verification

- `pnpm test` passed: ESLint and TypeScript checks.
- `pnpm verifyPlugins` passed: defaults, bundles, and featured plugin IDs resolve.
- `node --test packages/winaudio/test.js` passed all four Windows audio tests after building the candidate native module.
- Strict `pnpm overlay:vencord` passed with zero warnings; the artifact verifier passed all source-fingerprint, plugin, native-context, and startup-recovery checks.
- Authenticated candidate runtime checks confirmed `SpotifyControls` is registered/enabled, its slot is mounted before the account panel, `DMTierFlair` is registered/enabled, and the rendered MAXXER++ SVG has no white arc or text fallback.
- `pnpm package:dir` and `pnpm package:win` produced the unpacked build, x64 and arm64 ZIPs, the NSIS installer, blockmap, and `latest.yml`. The installer SHA-512 matches `latest.yml`.

## Remaining user acceptance

- A live Spotify track/device was not active during automation, so Diggy must start Spotify and click skip-next once in the installed release.
- Live voice and screenshare-with-audio remain unverified, as required by the project notes; they are optional quality checks and were not changed by this release.
