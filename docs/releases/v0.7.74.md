# Discordmaxxer v0.7.74

This update makes profile-widget skins usable after a reinstall or account switch when Discord still has the widget attached but the local editor fields are empty.

## What's changed

- The DMWidget editor recovers the public title, stats, layout, hero image, app icon, and widget identity from the attached Discord profile.
- A recovered game widget can now apply its Discordmaxxer skin without re-entering private Riot or Epic credentials.
- The new **Apply skin in Discordmaxxer** action keeps the existing published card unchanged and prevents an empty recovery form from overwriting it.
- Private game credentials remain local and are only required for live stat refreshes or intentional remote card-content updates.
- The editor continues to distinguish local Discordmaxxer rendering from Discord's native widget payload.

## Visibility boundary

Widget skins are Discordmaxxer-client rendering features. They do not become native Discord widget-v2 fields and are not guaranteed to appear in vanilla Discord.

An attached widget's published card remains on the owning Discord account. Copy/Import is still required when moving a widget between different Discord accounts.
