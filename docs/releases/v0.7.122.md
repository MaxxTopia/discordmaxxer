# Discordmaxxer v0.7.122

## Combined release candidate

This release groups the current reliability and presentation fixes into one
artifact instead of shipping the image path and profile-gradient path
separately.

## Highlights

- Hardened the image context-menu integration for both native image-context and
  message routes. Malformed image settings, duplicate menu injection, and
  custom image controls are isolated so they cannot take Discord down.
- Restored the native attachment click path so clicking a sent image can open
  Discord's normal enlarged viewer. The native message actions remain
  available for reply, forward, reactions, and the other standard actions.
- Added a DMEmoji error boundary around its custom message controls so a
  plugin-side failure does not crash the client or replace Discord's native
  menu.
- Made DMProfileCosmetics' Profile gradient (default) / Match profile gradient
  path use the canonical DMProfileFlair palette and identify the real action
  surface in the profile popout. The default action rows can therefore blend
  into the exact profile gradient rather than leaving a dark stock card behind.
- Strengthened DMTrim's sponsored/reward-card handling for Fanduel and similar
  placements whose card is already mounted or whose text arrives later. The
  bounded detector now performs delayed initial scans, watches relevant text and
  semantic attribute updates, and hides the coherent card-sized ancestor rather
  than only a button or text fragment. Normal messages still require the known
  promotional label/action combination.
- Hardened the pinned Vencord rebrand pipeline so the transitional PluginModal
  patches are idempotent across repeated overlay/package builds. A second build
  now remains a strict zero-warning build instead of falsely failing on patches
  that the final compact author renderer has already consumed.
- Kept the strict selected-window screenshare-audio candidate in this same
  release. When strict mode is enabled, a selected window is captured by its
  owning process and a failed resolution produces video-only output instead of
  leaking a system mix into the share. Voice and microphone capture are
  unchanged.

The signed-in visual and recipient checks remain acceptance gates for the
public release: right-click a sent image without a crash, click it to open the
enlarged viewer, confirm the normal message actions, verify the actual profile
popout matches the gradient showroom in default mode, and validate selected
Fortnite-window audio with a second listener. No public publish is claimed by
this document.
