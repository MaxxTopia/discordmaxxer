# Discordmaxxer v0.7.103

## Highlights

This release fixes profile media crossing between Discord accounts on the same
computer.

## Fixed

- Fixed a shared local profile slot that could make DiggyT display or publish
  DiggyAI's banner, animated avatar, gradient, or presentation settings.
- Profile media is now cached and edited per Discord account, while the shared
  Worker roster remains the cross-PC source of truth.
- The client waits for the current account's roster record before adopting
  legacy local media, preventing the wrong banner/avatar from flashing during
  startup or account switching.
- Save, clear, recent-media, color, and presentation controls now use the
  active Discord account boundary, so changing one account cannot overwrite
  another account's local profile state.
- Preserved the existing Worker-hosted banner and avatar files; no re-upload is
  required for accounts whose media is already present in the roster.

## Notes

- Discordmaxxer-only banners, animated avatars, gradients, widgets, and flair
  still require Discordmaxxer on both the owner and viewing client. Vanilla
  Discord cannot render those enhancements.
- Fully quit and relaunch Discordmaxxer after installing this release before
  testing account switching. Verify DiggyT -> DiggyAI and DiggyAI -> DiggyT;
  each account should keep its own banner, avatar, gradient, and widget skins.
