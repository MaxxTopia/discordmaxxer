# Discordmaxxer v0.7.101

## Highlights

This release fixes cross-install profile media and widget presentation, and
restores the branded Windows taskbar icon.

## Fixed

- Fixed animated profile banners and avatars becoming stale, missing, or
  different on another Discordmaxxer installation.
- Added automatic, throttled owner-media reconciliation so a client that can
  see the owner's saved media can repair the shared copy without repeatedly
  uploading or exhausting Worker quota.
- Fixed profile updates that clear media from being replaced later by an old
  local copy.
- Fixed Valorant, Fortnite, Now Playing, and other widget skins resolving from
  the viewer instead of the profile owner.
- Prevented widget skins and profile styling from briefly disappearing while a
  Discord profile or roster response is still loading.
- Added owner-scoped renderer markers so account switches and profile popouts
  cannot reuse another account's banner, theme, avatar, or widget styling.
- Restored the Discordmaxxer-branded Windows taskbar icon in packaged builds.

## Notes

- Cross-install profile media and widget styling still require Discordmaxxer on
  the viewing device; vanilla Discord cannot render these client enhancements.
- After installing, fully quit and relaunch Discordmaxxer. If Windows still
  shows a cached generic taskbar icon, unpin the old shortcut and pin the new
  Discordmaxxer shortcut once.
