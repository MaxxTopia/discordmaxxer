# Discordmaxxer v0.7.160

## Highlights

This maintenance release improves Discord renderer startup responsiveness and
prevents normal route transitions from being mistaken for a stalled client.

## Fixed

- Keep Chromium responsive during the bounded startup window while leaving the
  normal idle-throttling policy in place after startup.
- Treat the first visible Discord application shell as valid startup/liveness
  progress, so a slower route transition does not trigger an unnecessary
  recovery reload.
- Defer optional visual and UI plugin startup work until the Discord DOM is
  ready, reducing contention during the initial renderer mount.

## Verification

The release is gated by the strict Vencord overlay build, artifact-integrity
verification, application build, Windows packaging, and the documented
renderer validation checks. The signed-in startup, Tournament Mode, and DM
acceptance checks remain device-side checks after updating.
