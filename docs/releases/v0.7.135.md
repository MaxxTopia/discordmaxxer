# Discordmaxxer v0.7.135

## Highlights

- **Live Stats Zero-Key Auto-Refresh**: Bundled a verified shared HenrikDev API key for Valorant stats and wired auto-detection for Riot ID and Epic Games display names from connected Discord accounts (`riotgames` and `epicgames` connections in UserProfileStore). Live stat updates now work out of the box with zero manual API setup required.
- **Bot Token 2FA Challenge Handling**: Fixed the HTTP 401 code 60003 toast ("Two-factor is required for this operation") when clicking "Update widget content". If Discord challenges for 2FA when creating bot applications, the token minting step now logs gracefully without interrupting the local profile board deployment or static skin fallbacks.
- **Modal Avatar Circular Mask Preservation**: Fixed SVG `<foreignObject>` mask coordinates distortion where profile avatars clipped into red shapes inside the full profile modal. Removed interfering relative positioning from modal avatar images so Discord's native circular SVG clipPath remains pixel-perfect.
- **Profile Gradient & Banner Accent Restoration**: Removed the Discord SVG banner accent fill that was rendering as a solid cyan/red horizontal streak directly below user banners. Added translucent backdrops across inner profile layers (`userProfileInner`, `inner__`, `profileBody`) so full-card gradient styling flows smoothly from header to footer without washing out or clipping.
- **Instant Popout & Modal Flair Application**: Added rapid mutation scan intervals (0ms, 60ms, 180ms, 360ms) so animated avatars, custom banners, and gradient themes render instantly upon opening without lag or waiting on fallback timers.
- **High-Contrast Profile Text Legibility**: Added high-contrast white text color, drop shadows, and brightness/contrast adjustments for user tags, headings, and styled display names when viewed over vibrant custom profile themes.
- **DMTrim Announcement Card Visibility**: Stopped DMTrim from hiding legitimate announcement cards (such as `#products` posts with "Learn more" links and images). Unlabeled promotional cards now require ad-specific markup structure; generic CTAs alone no longer trigger hiding. Explicit ads (e.g. FanDuel) remain strictly filtered.
- **DMWidget REST POST/PUT/PATCH Direct Fallbacks**: Resolved the red toast error (`Discord REST POST API unavailable`) when clicking "Publish static skin for vanilla Discord". Added authenticated direct `fetch` fallbacks with `getDiscordToken()` when Discord's lazy webpack REST proxy is temporarily unavailable.
- **Foreign-User Profile & Board Visibility**: Added React Fiber parent walk (`findUserIdFromFiber`) in `DMProfileFlair` and `DMWidget` to resolve user IDs when users have default Discord avatars, and dispatched `USER_PROFILE_FETCH_SUCCESS` to hydrate `UserProfileStore` so foreign profile Boards and animated banners render properly in both popouts and full profile modal views.
- **SpotifyControls Robustness**: Hardened `SeekBar` with a `SliderClass` constructor check, safe-navigated artist arrays and album names in `Info`, and converted the ErrorBoundary in the account panel to a silent fail-closed fallback so "Failed to render Spotify Modal :(" is never rendered in the account panel.
