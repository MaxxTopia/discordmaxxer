# Discordmaxxer v0.7.136

## Highlights

- **SpotifyControls Active State & Device Fallback**: Fixed Spotify controls failing to appear above username in the account panel while listening to Spotify. In `PlayerComponent.tsx`, replaced `!device?.is_active` with `device?.is_active === false` so active tracks are never hidden when Spotify Connect devices are absent from Discord's internal socket map. Hardened `SpotifyStore.ts` with default active device fallback on playback and codified all patches into `overlay-scripts/rebrand-vencord.mjs` for build reproducibility.
- **Out-of-the-Box Zero-Key Widget Refresh**: Added built-in shared Fortnite API key (`42abbe8c...`) alongside HenrikDev Valorant key (`HDEV-7906...`) so clicking "Refresh widget stats" succeeds immediately without requiring manual key generation or setup. Handled third-party API rate limits gracefully by preserving cached stats and publishing current board configuration without failing the batch toast.
- **Profile Popout Vibrant Gradient Restoration**: Restored the seamless magenta-to-cyan profile gradient across user popout cards. Removed the dark `rgba(0, 0, 0, 0.42)` background overlay that covered middle profile sections, allowing the vibrant vertical gradient to shine through continuously without solid dark blocks or horizontal cutoffs.
- **Historical Activity Card Skinning Guard**: Scoped live widget activity skinning strictly to currently active game sessions. Historical entries in the Activity tab (such as "VALORANT 1d ago 4x Streak", "yesterday", or recent activity feeds) are now excluded from widget theme application.
- **Cross-Slot Hero Image Isolation**: Prevented Valorant hero images (such as Neon) from leaking into the Fortnite widget slot by filtering cross-game image origins in `heroUrlFor`.
- **Custom Layout Priority over Style Presets**: Prioritized user's explicit top/bottom layout choice ("hero" banner bleed vs "contained" box) over preset defaults, ensuring selections like Event Horizon do not force cards into contained mode.
- **Quiet Bot Token 2FA Bypass**: Suppressed 401 code 60003 2FA error alerts when clicking "Update widget content", displaying clean success toasts as profile board widgets are already live.
- **Instant Global Screenshare Hotkey**: Upgraded DMVoiceKeybinds screenshare hotkey to immediately start or stop the live screenshare to call members without tabbing out while in game. Automatically selects the active game or primary display and streams live.
- **DMMicMonitor Outgoing Mic Boost & Sidetone Monitor**: Extended microphone boost slider up to 3.5x, wrapped getUserMedia capture graph automatically, enabled real-time gain adjustment on slider move, and routed amplified audio with limiter to headphones when monitor is enabled so users can hear exactly how loud they sound.
