# Discordmaxxer v0.7.98

## Highlights

This release keeps cross-PC profile presentation stable while the shared profile
state is loading and makes owner-published widget styles authoritative.

## Fixed

- Fixed profiles briefly reverting to Discord's default gradient, banner, avatar,
  or flair while the shared profile roster is loading or refreshing. The client
  now keeps the last known good state until the replacement state is ready.
- Fixed cross-PC widget skins so the owner's published Fortnite and Valorant
  widget styles take priority over the viewer's local style. A viewer fallback
  may appear only while the owner's style is being read, then it is replaced by
  the owner's exact style.
- Added a safe migration for older locally-selected widget styles that do not
  yet have an owner marker. It is limited and confirmed after each write so it
  does not repeatedly update Discord or increase media/roster quota usage.
