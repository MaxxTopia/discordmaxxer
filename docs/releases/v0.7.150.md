# Discordmaxxer v0.7.150

## Highlights

- **Sanitize Fortnite Widget Application Name (`Fort` vs `.Fort`)**:
  - **Root Cause**: `sanitizeAppName` only stripped `:` colons and collapsed spaces without trimming leading/trailing periods, bullets, or punctuation delimiters. When registered or patched, Discord's card and profile pill displayed `[F] .Fort` instead of `[F] Fort`.
  - **Header & App Name Sanitization**:
    - Updated `sanitizeAppName` to explicitly strip leading and trailing periods, middle dots, bullets, slashes, and colons (`replace(/^[\s.·•:/-]+/, "").replace(/[\s.·•:/-]+$/, "")`), guaranteeing widget applications publish cleanly as `"Fort"`.
    - Sanitized `slotHeader("fortnite")` and `WidgetEditor` live preview to prevent stray dots in `fnChapterSeason` from rendering as `.Fort`.
    - Added proactive application name sanitization in `refreshAttachedWidgetStyles`: if the active Fortnite application name on Discord starts with `.` or equals `".Fort"`, it automatically sends a PATCH request to Discord's API to restore the official `"Fort"` name.
- **Restore User Theme (`NotAnotherAnimeTheme`)**:
  - Restored the official `NotAnotherAnimeTheme.theme.css` (by puckzxz#2080) to `%AppData%\discordmaxxer\themes\NotAnotherAnimeTheme.theme.css`.
  - Re-enabled `"NotAnotherAnimeTheme.theme.css"` in `%AppData%\discordmaxxer\settings\settings.json` under `enabledThemes`.
- **Restore Fortnite Hero Preset & Live Settings**:
  - Restored `fnHeroPreset: "catwoman"` and Catwoman hero image (`https://image.fnbr.co/outfit/5d8610e074b719851d631e9c/featured.png`) in `settings.json` so the Fortnite widget renders Diggy's preferred Catwoman artwork instead of unconfigured fallbacks.
  - Restored `fnEarnings: "$4,440"`, `fnUnrealRank: "Unreal"`, and `fnIgn: "ツDiggyTreeツ"`.
- **Session Migration for Release Preview Profiles**:
  - Added `%LocalAppData%\DiscordmaxxerReleasePreview-Codex\sessionData` to `migrateLegacyInstalledSessionData` candidates in `src/main/constants.ts` so preview and development installs seamlessly migrate session logins and cookies to release builds.
- **Clarify Widget Animations & Tournament Mode**:
  - Verified that widget animations (aurora, glint, embers, prism sweeps, and animated borders) operate continuously in normal mode.
  - Documented that Tournament Mode (`ctrl+alt+t`) pauses CSS animations (`animation-play-state: paused !important`) to save GPU/CPU cycles during competitive matches; toggling Tournament Mode off resumes all widget animations immediately.
