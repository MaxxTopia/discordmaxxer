# Discordmaxxer v0.7.119

## Highlights

- Publishes the DMHub plugin-settings crash hardening after aligning the overlay with the pinned Vencord `PluginModal` contract.

## Fixed

- Normalized missing plugin author metadata to an empty list before the native settings modal reads it.
- Guarded author overflow rendering so missing metadata cannot trigger an undefined `.length` or slice operation.
- Updated the overlay target to preserve Vencord's current `transitionState` modal prop, allowing the strict release build to apply every patch cleanly.

## Release boundary

The v0.7.118 tag was blocked by the strict overlay before packaging and did not publish an artifact. This patch is the corrected release candidate. The separate right-click image crash path remains a post-release user-acceptance test.
