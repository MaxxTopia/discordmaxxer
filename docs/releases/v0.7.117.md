# Discordmaxxer v0.7.117

## Highlights

- Makes plugin settings resilient to one broken or outdated plugin definition
  so the rest of Discord can continue running.
- Keeps the full animated profile, widget-skin, theme, and Tournament Mode
  work from v0.7.116 in the public updater build.

## Fixed

- Added a shared error boundary around plugin settings modals. A render-time
  settings failure now shows a contained error message instead of sending the
  entire renderer to Discord's crash-recovery screen.
- Added safe handling for missing plugin metadata and unsupported setting types.
- Hardened DMTrim stylesheet lifecycle and removed its risky relational CSS
  selectors so plugin reloads do not write through a detached style node.

## Release boundary

The source, strict Vencord overlay, lint/type checks, build, artifact
integrity, and Windows packaging are release gates. The contained settings
failure path still needs a signed-in client test: open DMTrim and another
plugin that previously crashed, then confirm Discord remains open. Voice,
screenshare, profile rendering, and benchmark comparisons remain separate
runtime acceptance checks.
