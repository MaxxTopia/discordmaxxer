# Discordmaxxer v0.7.72

This update improves profile-flair and widget-style reliability after reloads and updates.

## What's changed

- Tournament Mode now publishes its live state immediately. Turning it off restores animated profile media and widget motion on already-open surfaces instead of waiting for a later scan.
- Profile flair and widget rendering recover more safely when Discord returns partial profile data, including full-profile Board views and per-widget skin selections.
- Widget skin selection remains per game/widget, while the gallery selection is used as a safe recovery choice when older local state is incomplete.
- The profile-media Worker release is paired with this client update so shared avatar/banner publishing can reach the R2-backed media route instead of returning a missing-route error.
- The updater now has readable release notes for this version.

## Visibility boundary

Animated avatars, banners, gradients, and widget skins rendered by Discordmaxxer remain Discordmaxxer-client features. They are not represented as native Discord profile fields and are not guaranteed to appear in vanilla Discord.

Shared profile media still requires a successful claimed-account publish. A local preview or a failed upload does not make media available on another PC.
