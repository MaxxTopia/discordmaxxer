# Discordmaxxer v0.7.158

## Highlights

This maintenance release restores native image and video attachment previews
when a Discordmaxxer background is active.

## Fixed

- Keep VideoBackground's transparent clearing limited to Discord's app-frame
  layers instead of matching arbitrary hashed descendants.
- Preserve Discord's native pending attachment thumbnail, preview, and remove
  controls in DM and channel composers.
- Add a build-integrity regression guard for the unsafe descendant-wide CSS
  selectors that caused blank attachment cards.

## Verification

The candidate passed ESLint, TypeScript checking, strict Vencord overlay build,
artifact-integrity verification, application build, and Windows directory
packaging. A signed-in image/video selection, preview, remove, and send test
remains the user acceptance check after updating.
