# Discordmaxxer v0.7.104

## Highlights

This release revamps DMProfileFlair controls, brings native Playing activity card widget skin support, improves Tournament Mode feedback, enhances theme and tier flair options, and adds animated recent pick circles.

## What's New & Fixed

- **DMProfileFlair Controls**:
  - Fixed cursor jumping and right-click text selection issues in banner and avatar fields.
  - Replaced raw recent picks JSON with animated circular preview thumbnails.
  - Added clickable empty preview windows, file picker, and drag-and-drop file upload.
  - Direct upload & save pipeline through the VIP worker with automated validation.
  - Added inline media preflight showing file size, dimensions, duration, and limit feedback.
  - Crop anchor, fit, avatar scaling, media effects, and playback speed controls.
  - Moved manual claim code to the bottom of the plugin settings.
  - Removed deprecated vanilla normal Discord message compatibility bridge.
- **DMWidget & Activity Cards**:
  - Native Discord Playing activity cards (such as Valorant) now inherit the correct widget skins.
  - Dynamically synchronized Tournament Mode state mirror to prevent accidental card animation pauses.
- **Tournament Mode & VideoBackground**:
  - Reliable plugin-owned status banner for ON/OFF feedback without theme toast suppression.
  - Fixed VideoBackground test with sample and local video upload status feedback.
- **DMTierFlair & VIP**:
  - Updated MAXXER++ palette to champagne gold and deep wine red.
  - Added Champagne Sweep, Sunset Ember, and Aurora Ice badge finishes.
- **Playlistmaxxing Presence**:
  - Displays music.maxxtopia.com, song title, artist, artwork, progress bar, and startup/reconnect track hydration.
- **Welcome Tour**:
  - Trimmed preview GIF to eliminate blank frames; fixed broken image fallbacks and auto-scroll jump.
