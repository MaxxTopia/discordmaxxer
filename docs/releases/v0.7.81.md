# Discordmaxxer v0.7.81

This is attempt #4 at fixing the DMHub Create/Edit Profile Widget crash and
the grey recovery state that could follow a second open.

## What's changed

- DMHub now opens the DMWidget, Profile Flair, and Display Name Style settings
  through Discordmaxxer's stable plugin-settings route instead of Vencord's
  fragile plugin modal resolver.
- DMWelcome uses the same safe route for its profile settings shortcuts.
- The change covers the asynchronous null-Modal failure that happened after
  the button click, so a synchronous try/catch could not prevent the renderer
  crash.

## How to verify

After updating, fully restart Discordmaxxer, open DMHub, choose Create/Edit
Profile Widget, close the settings page, and open it again. The settings page
should appear both times without a crash or grey recovery screen.
