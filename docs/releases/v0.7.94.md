# Discordmaxxer v0.7.94

This release restores the original two-style Catwoman hero artwork for the
Fortnite widget preset.

## Highlights

- The Catwoman preset now uses the verified 1024px Featured render showing
  both Catwoman edit styles, matching the original Discordmaxxer widget look.
- Existing published widgets and account data are not rewritten automatically;
  select Catwoman and save the widget once if you want to update an existing
  card.
- The change is limited to the Fortnite Catwoman preset. Other hero presets,
  widget styles, profile data, and account-specific settings are unchanged.

## Important limits

- The artwork is loaded from a public image host at runtime. If that host ever
  changes or becomes unavailable, the preset will need a first-party asset
  fallback.
- This release does not change Discord's vanilla-client limitations: custom
  Discordmaxxer widget rendering remains visible to Discordmaxxer clients.
