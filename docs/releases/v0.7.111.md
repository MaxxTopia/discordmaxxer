# Discordmaxxer v0.7.111

## Highlights

Comprehensive overhaul and optimization of `DMCursor`, restoring all anime skin animations (Sharingan spinning tomoe, Rinnegan rippling rings & orbiting chakra dots, Rasengan multi-layered swirling chakra storm, Chidori crackling electric lightning), and drastically improving cursor responsiveness, snappiness, and CPU/GPU performance.

## What's New & Fixed

- **Restored & Enhanced Anime Cursor Animations**:
  - **Sharingan**: Restored 3-tomoe center rotation via native SVG transform and CSS `transform-box: view-box; transform-origin: 50% 50%`, fixed missing center pupil element, and deepened red chakra pupil pulse.
  - **Rinnegan**: Added phased rippling purple rings outward from the center pupil and smooth continuous chakra dot orbit around the outer ring.
  - **Rasengan**: Upgraded chakra rings with distinct dashed arcs and multi-directional high-speed rotations (clockwise & counter-clockwise) creating a vivid, visible swirling chakra storm.
  - **Chidori**: Added high-voltage crackling electric lightning animations with staggered delays and vibrating blue core.
  - **Stiiizy**: Preserved pulsing green LED and modernized smoke particle drifts.
- **Latency & Performance Optimizations**:
  - **Main Thread Event Throttling**: Decoupled expensive smoke emission and DOM math from the high-frequency `mousemove` listener. Coordinates are buffered into a lightweight `requestAnimationFrame` tick, eliminating CPU main thread flooding from 1000Hz+ gaming mice.
  - **MutationObserver Shielding**: Spawns Stiiizy smoke particles inside a dedicated, isolated `.dm-cursor-smoke-container`, completely preventing Discord and plugin MutationObservers from waking up or running expensive selector passes on `document.body`.
  - **Eliminated Universal `*` Selector**: Replaced `html.anime-cursor-active *` with targeted interactive element selectors, eliminating layout/style recalculation penalties across 20,000+ DOM nodes.
  - **GPU Layer Optimization**: Replaced heavy multi-pass drop shadow filters with single-pass hardware-accelerated glows, eliminating continuous offscreen Gaussian blur re-rasterization.
