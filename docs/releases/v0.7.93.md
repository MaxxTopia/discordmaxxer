# Discordmaxxer v0.7.93

This release moves existing VIP bindings onto the shared server validation
path without replaying the one-time claim operation on every launch.

## Highlights

- Shared license validation now checks the read-only Worker validation route
  and refreshes server-provided expiry and product-scope metadata.
- Explicit expiry, revocation, HWID mismatch, scope mismatch, and reset
  responses clear the local binding instead of leaving stale access active.
- A bounded offline grace window keeps a valid session usable during a short
  Worker outage, while client-clock rollback fails closed.

## Important limits

- Existing legacy bindings remain compatible until they are reissued or
  migrated; the shared Worker remains the authority for new claims and
  server-backed validation.
- A real signed-in cross-PC Discordmaxxer check still needs to be run after
  installation. This release does not claim to have verified live voice or
  screenshare-with-audio behavior.
