# Discordmaxxer v0.7.92

This release tightens cross-account profile rendering, makes the Hub easier to
navigate, and aligns Founder access with the one-time offer shown on the VIP
page.

## Highlights

- Owner-published widget skins now take priority over the viewer's local skin
  when viewing another Discordmaxxer user's profile.
- Foreign profile banners get one bounded roster refresh when a stale shared
  media URL fails, helping another PC converge without creating a retry loop.
- The Fortnite hero preset now uses the two-style Catwoman artwork, while
  existing published widgets remain unchanged until their owner republishes.
- DMHub now opens the Video Background editor directly; playback is free and
  saved-slot limits still follow the user's tier.
- Founder claims now mean $67 once for lifetime MAXXER+, a permanent numbered
  Founder badge, and no required subscription; MAXXER++ remains optional.
- Release notes are attached to the GitHub release so the in-app updater shows
  readable highlights instead of the generic unreadable-notes message.

## Important limits

- Discordmaxxer profile flair, shared banners, animated avatars, and widget
  skins are rendered by Discordmaxxer clients. Unmodified vanilla Discord does
  not render these features.
- Cross-PC recipient rendering still needs a real DiggyT-to-DiggyAI check after
  both clients install or update to this build.
