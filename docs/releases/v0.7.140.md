# Discordmaxxer v0.7.140

## Highlights

- **Instant Profile Popout "Playing Discordmaxxer" Activity Card Skinning**: Fixed the 1-second delay and flash of unskinned vanilla dark-grey content when opening the user profile popout.
  - **Account Popout Immediate Ownership**: In `widgetSurfaceBelongsToCurrentUser()`, immediately recognize `accountPopout` and account action triggers ("Edit Profile", "Online >") as belonging to the signed-in user without waiting for asynchronous profile owner hydration or avatar URL checks.
  - **Outer Profile Boundary Scoping**: In `widgetSurfaceForCard()`, prioritize returning the outermost profile boundary (`surfaces[surfaces.length - 1]`) rather than the innermost wrapper (`surfaces[0]`). This ensures both the game widget and the active "Playing" card share the same profile context, allowing the Rich Presence card to inherit the active design synchronously on mount.
  - **Fixed Missing Scope in `playingCardPreset`**: In `playingCardPreset()`, resolved `const localHints = knownWidgetHints()` which was throwing a silent `ReferenceError: localHints is not defined` inside candidate card resolution.
  - **Broadened Activity Card Matching & Dimensional Bounds**: In `isDiscordmaxxerPlayingCard()` and `widgetCardLike()`, expanded class matching to include `activity` and `interactive`, and lowered bounding-box threshold to `rect.width < 120 || rect.height < 36` (matching all other card selectors) so cards undergoing mount animations are not rejected.
  - **Targeted Fast-Path Query**: In `scanVisibleProfileWidgetCards()`, simultaneously queried both `WIDGET_CARD_SELECTOR` and `PLAYING_CARD_SELECTOR` so the Playing card is never crowded out by badges or listitems.
  - **Immediate Synchronous Scan on Mount & Trigger**: Triggered synchronous `scanVisibleProfileWidgetCards()` immediately on click / focusin and inside the `MutationObserver` callback so the skin is attached on the exact frame the popout DOM is added before paint.
  - **Reduced Probe Throttling**: Decreased `PLAYING_CARD_DIRECT_PROBE_INTERVAL_MS` from 1000ms to 150ms and kept `widgetSkinPlayingCardProbeRequested` active until a candidate is confirmed.
