# Discordmaxxer v0.7.159

## Highlights

This maintenance release restores the normal Discord image and video
attachment composer when VideoBackground or the DMEmoji button is enabled.

## Fixed

- Keep VideoBackground from clearing background images that Discord uses for
  native pending attachment media.
- Leave Discord's React-owned composer untouched until the upload store reports
  a real pending attachment, preventing an empty third-party host from blanking
  the attachment list.
- Extend the build-integrity checks so both regressions fail before packaging.

## Verification

The candidate must pass ESLint, TypeScript checking, the strict Vencord overlay
build, artifact-integrity verification, application build, and Windows
packaging. A signed-in image/video selection, preview, remove, view, and send
test remains the final user acceptance check after updating.
