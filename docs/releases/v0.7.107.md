# Discordmaxxer v0.7.107

## Highlights

Major performance overhaul eliminating lag and frame drops in Settings and the Plugins tab, crash prevention and memory leak fixes for external media streaming, DMCursor fluid hardware-accelerated tracking, full avatar-and-name wrapping for conversation header widget skins, and synchronized Playlistmaxxing rich presence.

## What's New & Fixed

- **Settings & Plugins Performance Overhaul**:
  - Implemented CSS render containment (`content-visibility: auto; contain-intrinsic-size: 0 100px;`) on all plugin cards. Chromium now skips layout, styling, and paint for ~235 off-screen plugin cards, reducing the plugins tab rendering workload by ~95% and eliminating scroll stutter.
  - Scoped `useSettings` in the Plugins tab to `plugins.*` with a static array reference, preventing global setting writes elsewhere in the app from triggering tab re-renders and re-sorting 250 plugins.
  - Isolated MutationObservers across `DMTierFlair`, `DMTyping`, `DMProfileFlair`, and `DMHub` to ignore mutations originating inside Settings layers and pause background document sweeps while User Settings is open.
  - Filtered profile banner discovery with fast dimension pre-checks to eliminate synchronous `getBoundingClientRect()` layout reflows on the main UI thread.
- **Client Stability & Media Proxy Hang-up Fix**:
  - Added a 30-second negative cache (`failureCache`) in `dmMediaProxy.ts` so failed or hung upstream media requests (e.g. Catbox MP4 banners) immediately return 502 rather than spawning hundreds of parallel hanging connections in an infinite loop.
  - Added a 10-second socket timeout on media requests to prevent hanging sockets and eliminate `MaxListenersExceededWarning` WebContents listener leaks.
  - Switched media proxy headers to a standard Chrome browser User-Agent so CDNs no longer reset connections on bot detection.
  - Added a module-level failure cooldown in `DMProfileFlair` to stop re-requesting dead URLs across popout mounts.
- **DMCursor Fluidity & Latency Fix**:
  - Converted custom cursor tracking to `requestAnimationFrame` batching using GPU-accelerated CSS `transform: translate3d(x, y, 0)`.
  - Eliminated synchronous layout thrashing during fast cursor movements across all custom skins (Sharingan, Rinnegan, etc.).
  - Added distance and time throttling to the Stiiizy smoke particle trail to prevent rapid DOM element creation on high-polling-rate gaming mice.
- **DMWidget Conversation Header Skins**:
  - Fixed 1-on-1 DM conversation header surface skins so the custom style wraps both the recipient avatar and username together as a unified surface rather than leaving the avatar detached or rendering a compact layout.
- **Playlistmaxxing Rich Presence Sync**:
  - Synchronized track metadata, album artwork resolution, and presence activity payloads to display current song title, artist, album art, and "Listening on music.maxxtopia.com" rich presence status.
