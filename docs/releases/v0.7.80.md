# Discordmaxxer v0.7.80

This is attempt #3 at hardening widget skins after the Create/Edit Profile
Widget crash and reopen failure.

## What's changed

- The Board skin scanner now suspends while the DMWidget editor mounts, cancels
  queued scans, and rechecks that guard before any deferred work runs.
- DOM, React, and mutation discovery are bounded and scoped so opening the
  editor cannot trigger a page-wide renderer scan.
- Account switches and rapid skin selections no longer let stale async work
  overwrite the current account or the newest widget style.
- Editor actions, gallery actions, and scheduled stat refreshes fail safely
  with a status message instead of leaking an unhandled renderer rejection.
- Apply feedback now distinguishes a saved style from a widget card that was
  actually restyled on screen.

## Visibility boundary

Widget skins remain Discordmaxxer-rendered presentation. They do not become
native Discord widget fields for vanilla Discord users. After updating, fully
restart Discordmaxxer and reopen the profile Board before testing the editor or
applying a skin.
