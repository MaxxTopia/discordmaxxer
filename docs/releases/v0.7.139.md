# Discordmaxxer v0.7.139

## Highlights

- **Widget Live Stats Persistence & Cross-Account Identity Fallback**: Fixed widget stats disappearing or reverting to dashes (`—`) and title defaulting to "Valorant".
  - Backed `fnStats` and `valStats` with persistent `localStorage` and settings cache so live stats are preserved across restarts and page reloads.
  - Implemented `getEffectiveRiotId()` and `getEffectiveFnIgn()` with persistent cross-account fallback so accounts without linked Discord connections automatically resolve Diggy's identities (`ツDiggy ナ#Fort` and `ツDiggyTreeツ`).
  - Added robust fallback stat lines in `valorantStatLines()` and `fortniteStatLines()` so cards never publish or render empty dashes when waiting for API refresh.
  - Automatically save updated stats to persistent storage upon every live refresh or widget snapshot hydration.
- **Profile Text Darkness & Heading Glitch Fix**: Fixed section headings (`Bio`, `Member Since`, `Connections`, `Note`) and username handles appearing dark, blurry, and smudged.
  - In `plugins/DMDisplayNameStyle`, explicitly excluded section headings, tabs, and metadata labels from matching `hasNameClass`, ensuring only genuine user display names receive display-name styling.
  - In `plugins/DMProfileFlair`, removed the aggressive 8px black aura (`text-shadow: 0 0 8px rgba(0, 0, 0, 0.8)`) and duplicate drop-shadow filter on styled names, providing crisp, clean, high-contrast text across all profile themes.
