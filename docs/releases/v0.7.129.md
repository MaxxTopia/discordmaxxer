# Discordmaxxer v0.7.129

## Highlights

- Adds a bounded startup watchdog that reports overlay, navigation, renderer, and plugin-preparation failures instead of leaving users at a permanently blank window.
- Adds a recovery screen with Retry Discord, Restart Discordmaxxer, and Open startup log actions.
- Verifies the packaged Discordmaxxer Vencord overlay before startup and fails closed with recovery when the bundle is missing, stale, or tampered with; packaged clients no longer silently download a stock overlay that can omit Discordmaxxer plugins.
- Rebuilds the release overlay from a clean pinned Vencord checkout so the public artifact cannot inherit the damaged partial source tree used by the failed candidate.

## Verification

- TypeScript, production build, strict overlay, staged-source verifier, packaged directory smoke test, and startup-log checks are run before publication.
- A signed-in user should verify a cold launch, refresh, profile/widget skins, normal and image message context menus, full-screen image right-click behavior, DMEmoji send/preview, display names, profile flair, themes, screenshare audio/video, and Tournament Mode after updating.
