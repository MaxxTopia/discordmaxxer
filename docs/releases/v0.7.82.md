# Discordmaxxer v0.7.82

This is attempt #5 at fixing the DMHub Create/Edit Profile Widget editor and
the existing-widget skin workflow.

## What's changed

- DMHub now opens the real DMWidget editor again through a compatible modal
  implementation instead of only opening the generic plugin list.
- DMProfileFlair and DMDisplayNameStyle shortcuts use the same safe editor
  path, with a settings-page fallback if a plugin is still loading.
- Existing published widgets can be recovered for skin-only editing without
  re-entering private game credentials. Applying a skin updates the
  Discordmaxxer renderer state and keeps the native published card intact.
- Widget skins now render in the Discordmaxxer profile popout with their
  selected frame, ornament, glow, and motion settings, and the selection is
  synced for the user's other Discordmaxxer installs.
- The release verification covered opening, closing, and reopening the editor,
  then applying Frosted Glass to an already recovered Valorant widget and
  checking the rendered skin attributes and active animations.

This release does not add Discordmaxxer-only CSS effects to vanilla Discord.
The native published widget remains the compatibility surface for vanilla
Discord users.
