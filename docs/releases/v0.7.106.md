# Discordmaxxer v0.7.106

## Highlights

Enables cross-client widget skin rendering so other Discordmaxxer users can see your customized widget skins, gradient frames, and card layouts when viewing your profile.

## What's New & Fixed

- **Cross-Client Widget Skins**: Fixed an issue where other Discordmaxxer clients viewing your profile saw unskinned widget cards. The visible widget style hydration path now queries Discord's public RPC endpoint (`/applications/{id}/rpc`) rather than the developer-only endpoint (`/applications/{id}`), allowing non-owner viewers to reliably retrieve the application's published `[DMWSTYLE1]` skin and layout markers without hitting 403 Forbidden.
- **Surface Filter Repair**: Fixed an inverted boolean condition in `visibleProfileWidgetStyles` and `visibleProfileWidgetHints` that discarded cached remote widget styles when surface ownership was still resolving.
- **Owner Marker Synchronization**: Fixed an edge case where an uninitialized `widgetStyleUpdatedAt` prevented background repair passes from syncing the remote description marker.
