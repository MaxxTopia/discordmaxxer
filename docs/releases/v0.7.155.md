# Discordmaxxer v0.7.155

## Highlights

This maintenance release hardens startup recovery after a transient Discord
navigation delay.

## Fixed

- Automatically retry startup when Discord has not rendered within the initial
  watchdog window, instead of immediately showing the recovery dialog.
- Ignore stale navigation failures from an earlier attempt so a late error
  cannot replace a newer successful retry with a false failure.
- Record each timeout, retry, and successful recovery in `startup.log` for
  diagnosis when Discord or the network is genuinely unavailable.

The recovery dialog remains as a bounded final diagnostic after repeated
automatic attempts; it is no longer the response to one slow launch.
