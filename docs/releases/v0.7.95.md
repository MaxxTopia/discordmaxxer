# Discordmaxxer v0.7.95

This release makes the free profile showcase useful, makes the Founder offer
plain, and carries the recent profile, widget, and plugin reliability work
into the published client.

## Highlights

- **Free profile showcase:** a claimed free account can use one active
  animated banner, one active animated avatar, and a two-color profile theme
  for other Discordmaxxer clients to see. The media is not downgraded on free;
  paid tiers add presentation controls and larger saved-media limits.
- **Cross-install profile rendering:** shared profile data is resolved for the
  account being viewed, so the viewer's own banner, avatar, colors, or widget
  skin no longer replaces the other user's choices.
- **DMProfileFlair:** banner and avatar previews stay beside their inputs;
  color fields show live swatches and colored hex text; recent picks and
  status toasts make save, clear, broadcast, and fallback actions explicit.
- **Widget and Fortnite polish:** widget previews remain visible, the curated
  hero gallery is easier to choose from, and the restored Catwoman preset uses
  the verified two-style artwork. The Diggyai-only remembered/default choice
  remains account-scoped.
- **Plugin usability:** DMHub shortcuts and setup guidance, DMTheme controls,
  DMTierFlair finish previews, DMTranslate's message context action, DMVotes
  prompts, and the related toast/status cleanup are included.
- **Free video backgrounds:** video playback remains available on the free
  tier; paid tiers expand saved URL capacity and presentation limits.
- **Founder Pass:** the first 33 numbered Founder slots are `$67 once`, with
  lifetime MAXXER+, a Founder badge, and no recurring charge or auto-renewal.
  The in-client and website cards keep the **Claim a Founder slot** action.
- **Readable release notes:** the release workflow now attaches this file to
  the GitHub release so the in-app updater can display the actual notes.

## Important limits

- Discordmaxxer profile flair and widget skins are client-rendered features.
  An unmodified vanilla Discord client cannot display them.
- Native Discord uploads and native profile colors remain subject to
  Discord/Nitro rules; the plugin surfaces the result instead of claiming a
  successful upload when Discord rejects it.
- Cross-PC behavior still depends on the other installation running this
  release (or a later one) and being signed in to the same shared service.
