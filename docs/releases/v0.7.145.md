# Discordmaxxer v0.7.145

## Highlights

- **Direct Voice Call Screen Share Hotkey (Start & Stop)**:
  - Fixed `DMVoiceKeybinds` screenshare hotkey (`ctrl+alt+s` by default, configurable) failing to start a stream:
    - **Root Cause**: The previous implementation performed a broad, unconstrained `document.querySelectorAll` across the entire DOM looking for any element with the substring `"stream"` in its inner text or attributes. In chat channels, DM conversations, or server feeds containing messages, channel titles, or member names with the word "stream", unrelated elements received a false-positive match score. Calling `.click()` on an arbitrary message element did nothing while still triggering the toast `"🖥️ Starting live stream to voice call…"`.
    - **Voice Connection Gatekeeper**: Added an upfront `isVoiceActive()` check against Discord's `SelectedChannelStore`, `RTCConnectionStore`, and `ChannelRTCStore`. If the user is not connected to a voice channel or call, the hotkey immediately displays a clear prompt (`"🖥️ Join a voice channel first — screen share is unavailable here"`) and exits early without false-positive toasts.
    - **Scoped Voice Control Discovery**: Implemented `findVoiceControlButton()`, which restricts element searches to valid voice and call control areas:
      - Bottom-left voice panels: `section[class*="panels_"]`, `div[class*="connection_"]`, and `div[class*="voice_"]`.
      - Active call docks and overlays: `[class*="callContainer_"]`, `[class*="videoControls_"]`, `[class*="bottomControls_"]`, and `[class*="wrapper_"][class*="call_"]`.
      - Strict voice aria-labels: strictly matches `/share\s*(your\s*)?screen|screen\s*share|go\s*live/i` while rejecting camera/video controls.
    - **Synthetic Event Lifecycle**: Implemented `simulateClick()` which dispatches the complete pointer and mouse event chain (`pointerdown` → `mousedown` → `pointerup` → `mouseup` → `click` → `.click()`) directly on the outer `<button>` or `[role="button"]` container, ensuring React 18 event delegation and pointer handlers trigger reliably even when Discord is unfocused while gaming.
    - **Instant Auto-Start**: Pre-arms `(globalThis).__dmAutoStartScreenShare = true` prior to dispatching the button click, allowing `ScreenSharePicker` to instantly select the running game or primary monitor and begin broadcasting without requiring manual clicks or tabbing out.
    - **Modal Auto-Submit Watcher**: Added an interval watcher that automatically detects and clicks any modal confirmation buttons (`"Go Live"` / `"Share"`) if Discord opens a stream configuration dialog.
    - **Clean Stream Toggle (Stop on Active)**: If an active stream is already running (verified via `ApplicationStreamingStore.getCurrentUserActiveStream()` and UI stop buttons), pressing the hotkey cleanly terminates the stream via `StreamActions.stopStream()`, dispatches `STREAM_STOP` via `FluxDispatcher`, clicks the active stop button, and toasts `"🖥️ Live stream ended"`.
