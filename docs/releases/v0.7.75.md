# Discordmaxxer v0.7.75

This update makes the existing-widget skin workflow clear and credential-free.

## What's changed

- Recovered widgets open in **skin-only mode** by default.
- Applying a skin to an existing widget no longer requires a Riot ID, Name#Tag, or HenrikDev key.
- The editor now separates **Apply skin to existing widget** from **Update widget content**.
- Live-stat credentials are hidden until **Edit live stats/content** is selected.
- Content updates and stat refreshes clearly indicate when private credentials are required, preventing an empty recovery form from replacing a valid published card.

## Visibility boundary

Widget skins are Discordmaxxer-client rendering features. They do not become native Discord widget-v2 fields and are not guaranteed to appear in vanilla Discord.

An attached widget's published card remains on the owning Discord account. Copy/Import is still required when moving a widget between different Discord accounts.
