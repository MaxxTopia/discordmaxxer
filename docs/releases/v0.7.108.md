# Discordmaxxer v0.7.108

## Highlights

Fixed client crash when opening DMEmoji from the chat bar, modernized DMEmoji to use Discordmaxxer's stable modal architecture with error boundary isolation, improved emoji storage and retrieval reliability, and added DMEmoji to default-enabled seed configuration and build verification.

## What's New & Fixed

- **DMEmoji Crash Fix & Modern Modal Architecture**:
  - Replaced Discord's broken mangled `Modal` import from `@webpack/common` with Discordmaxxer's stable `ModalRoot`, `ModalHeader`, `ModalContent`, and `ModalCloseButton` primitives.
  - Wrapped modal mounting in an `ErrorBoundary` and guarded chat bar button click handlers with `try / catch` so runtime modal errors can never crash the Discord client or trigger the reload screen.
  - Provided a resilient standalone modal fallback shell with keyboard (`Escape`) and backdrop-click dismiss handlers in case Discord modal primitives fail to resolve.
- **DMEmoji File Handling & Safety**:
  - Enhanced `getEmojiFile()` to safely deserialize `Blob`, `File`, `ArrayBuffer`, or `ArrayBufferView` data from IndexedDB without throwing.
  - Added channel validation and error toasts to `sendEmojiAsImage()` to ensure graceful feedback if an emoji cannot be attached.
  - Improved emoji grid layout with rounded preview wrappers preventing clipping on square and rectangular emojis.
- **Default Seeding & Build Verification**:
  - Added `DMEmoji` to `src/main/discordmaxxerDefaults.ts` so new Discordmaxxer users automatically have access to the local emoji library.
  - Added `DMEmoji` to `REQUIRED_PLUGINS` in `overlay-scripts/verify-build.mjs` to guarantee the plugin is compiled into every production renderer build.
