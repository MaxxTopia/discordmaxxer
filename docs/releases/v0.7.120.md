# Discordmaxxer v0.7.120

## Highlights

- Fixed the shared plugin-settings window so missing or changing plugin metadata, settings definitions, and contributor data cannot crash the modal. The settings shell now uses a stable modal contract and keeps plugin-specific controls isolated.
- Fixed left-clicking a Discord image attachment so it opens Discordmaxxer's enlarged image viewer again, with zoom, navigation, browser, more, and close controls. The ImageZoom overlay no longer swallows the native attachment click.
- Pinned the Vencord source contract for both local and release builds so the development client and public installer compile the same renderer patches.

## Verification

- Strict Vencord overlay: 111 patches applied or already present, 0 warnings.
- `pnpm test`, `pnpm build`, `node overlay-scripts/verify-build.mjs`, and `pnpm package:dir` passed.
- The exact packaged v0.7.120 executable opened DMProfileCosmetics, DMTrim, DMWidget, DMTierFlair, DMEmoji, and PlaylistmaxxingPresence settings without the previous `.length` error or React render loop.
- The exact packaged executable opened a real Discord image attachment in the enlarged viewer after a normal left-click.

Voice, screenshare, and other live account/device behavior remain user acceptance checks rather than claims made by the automated package test.
