# Discordmaxxer v0.7.87

This patch release carries the packaged-client repairs validated after the
v0.7.86 widget/profile release.

## What's changed

- Restored the renderer's normal HTML display defaults so the packaged client
  opens into Discord instead of exposing raw renderer source or a grey shell.
- Kept profile flair media persistent and layered the animated banner behind
  the profile avatar in popouts and full-profile views.
- Limited widget-skin application to the intended open conversation/profile
  surfaces while preserving the existing Board and Playing-card behavior.
- Prevented the Playing-card cleanup rule from clearing the card's own skin
  background and animated pseudo-layers, eliminating the flat or hover-only
  appearance.

Widget skins and profile flair remain Discordmaxxer-rendered enhancements; they
do not make Discordmaxxer-only visual effects appear in vanilla Discord.
