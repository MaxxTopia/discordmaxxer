# Discordmaxxer v0.7.110

## Highlights

Comprehensive fix and overhaul of conversation header widget skins in `DMWidget`, ensuring seamless, unified avatar and username capsule wrapping on 1-on-1 direct messages across all name lengths, fixing clipping on medium-length names, and resolving detection failures on short names.

## What's New & Fixed

- **Universal Conversation Header Skinning for All Name Lengths**:
  - Lowered minimum width and height filters for open conversation headers from 80px/32px to 10px/12px in `visibleSurfaceSkinTarget`, allowing short names (e.g., 2–5 characters like "Al", "Ed", "Bob") to reliably receive widget skins instead of failing visibility checks.
- **Robust Avatar Sibling Detection for 1-on-1 DMs**:
  - Overhauled `isHeaderAvatarElement` to reliably recognize avatar containers containing hidden accessibility text (such as screen reader status messages) without prematurely rejecting them.
  - Expanded avatar selector matching to support standard Discord avatar wrappers, images, mask SVGs, and foreignObjects within header containers.
- **Unified Avatar & Username Capsule Wrapping**:
  - Enhanced `syncHeaderAvatarSurface` to calculate dynamic gap offsets and apply the `--dmw-avatar-offset` / `--dmw-avatar-pad` capsule geometry cleanly to conversation headers while preserving inner text position and alignment.
  - Added parent overflow un-clipping (`overflow: visible !important`) via CSS `:has()` and runtime ancestor style adjustment, preventing layout containers from cutting off the left edge of the avatar capsule.
  - Maintained distinct handling for group DMs and server channels where avatars/icons are already embedded within the title container.
