## Runtime boundary

Outgoing boost remains off by default. Enable it from DMHub -> Voice & input ->
Mic boost, sidetone & level monitor, use headphones for the local preview, and
reconnect voice if already in a call. The local preview is an approximation
because Discord may apply additional voice processing; a real recipient check
is still required for final loudness and clarity.
