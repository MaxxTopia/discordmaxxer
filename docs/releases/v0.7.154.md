# Discordmaxxer v0.7.154

## Highlights

This maintenance release repairs DM attachment previews and restores the
MessageLogger cleanup action for greyed deleted messages.

## Fixed

- Fixed DM image and video previews appearing blank before a message is sent.
- Kept the pending attachment card visible when Discord provides a cross-realm
  upload object or delays native media rendering.
- Rebound the pending attachment preview when Discord replaces the composer
  during navigation or upload.
- Restored `Remove Message History` for MessageLogger's greyed deleted-message
  entries while keeping unrelated native message-menu patches blocked.
- Carried forward the SpotifyControls stability and playback-control repairs
  from the previous release line.
