# Discordmaxxer v0.7.123

## Image context-menu crash fix

This release targets the renderer crash that could occur when right-clicking
an image sent in a Discord message.

## Highlights

- Removed Discordmaxxer's broad ImageZoom `message` context-menu hook. Image
  messages now stay on Discord's native context-menu route, preserving the
  normal reaction, Reply, Forward, attachment, and image actions.
- Kept ImageZoom's optional image-specific controls guarded without injecting
  them into the general message menu.
- Made DMEmoji leave image attachments and image/GIF embeds untouched while
  retaining its search/react and saved-media controls for text messages.
- Preserved the native image click path so clicking an image can open the
  enlarged Discord viewer.
