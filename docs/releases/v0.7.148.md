# Discordmaxxer v0.7.148

## Highlights

- **Overhaul MAXXER++ Tier Badge Visuals, Animation, and Tooltip Wording**:
  - **Concise, Clean Tooltip Wording**:
    - Replaced the verbose 67-character text (`"MAXXER++ tier badge — selectable finish with an optional light sweep"`) that rendered as 4 lines of awkward bold all-caps text with a clean, official single-line title:
      - `MAXXER++ Supporter`
  - **Crisp Geometric Vector Emblem (No Font Fallbacks)**:
    - Replaced the previous `<text font-family="...">++</text>` implementation that fell back to chunky blocky Arial Black glyphs with precision-drawn SVG rounded cross geometry (`<rect rx="0.7">`).
    - Added an embossed 3D bevel shadow underneath the emblem for an authentic minted coin appearance.
  - **Reliable Smooth Light Sweep Animation**:
    - Replaced the broken SMIL coordinates with dual CSS `@keyframes` and SMIL fallback animation.
    - Soft gradient beam (`stop-opacity="0"` to `"0.9"` to `"0"`) sweeps smoothly across the circular face from top-left to bottom-right every 2.8 seconds.
  - **Minted Metallic Bevel and Finish Profiles**:
    - Added a dual-tone metallic outer bevel stroke (`stroke="url(#dmpp-ring-${finish})" stroke-width="1.1"`) and a specular upper-rim arc highlight.
    - Scoped gradient IDs by `${finish}` (`dmpp-base-${finish}`, `dmpp-clip-${finish}`, `dmpp-shine-${finish}`) to eliminate ID collisions in multi-card preview views.
  - **Discord Profile Badge Glow & Hover Interaction**:
    - Added CSS rules for `img[src*="dmpp"]` with an ambient glow halo matching the active finish (Gold, Sunset, or Aurora) and a smooth `scale(1.1)` hover response.
  - **Interactive Finish Picker**:
    - Made each finish preview card in `BadgeFinishPreview` directly clickable, allowing users to switch finishes with one click.
