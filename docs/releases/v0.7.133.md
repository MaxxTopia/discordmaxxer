# Discordmaxxer v0.7.133

## Highlights

- Makes DMMicMonitor's local audition follow the same bounded outgoing boost and compressor stage used for the microphone track sent to voice-call recipients. Monitor gain remains a separate local headphone-volume control.
- Clarifies the microphone controls and level meter so users can tell what other people receive from what is only heard locally.
- Keeps the microphone path isolated from screen-share capture and keeps the native-stream fallback available if the processing graph cannot start.
- Makes the Spotify track and active-device normalization patch safe to apply repeatedly during rebuilds, avoiding duplicate generated helpers and malformed store boundaries.
- Carries forward the verified v0.7.132 startup, composer, image-menu, folder, widget, theme, DMTrim, keybind, and plugin-recovery fixes.

## Runtime boundary

The outgoing boost remains off by default. Enable it from DMHub -> Voice & input -> Mic boost, sidetone & level monitor, use headphones for the local preview, and reconnect voice if already in a call. The local preview is an approximation because Discord may apply additional voice processing; a real recipient check is still required for final loudness and clarity.
