# Discordmaxxer v0.7.144

## Highlights

- **DMWidget Visual Showroom & Action Bar Restoration**:
  - Restored the full visual showroom (`WidgetStylePicker`) to the top of the DMWidget settings modal:
    - 3 independent widget selection tabs (`Valorant`, `Fortnite`, and `Custom`) allowing distinct skins and configurations for each widget without cross-card leakage.
    - 9 art-directed skin preset cards with live animated swatches, glowing aura cards, layout tags, and mood descriptors.
    - Interactive live preview card with sizing toggles (`Compact` and `Expanded`) rendering live card title, header, hero cutout art, and stat grid / progress bar.
    - Local hero image upload and removal controls with instant local preview.
  - Added a dedicated, prominent Action Bar directly within the showroom at the top of the modal:
    - `Apply skin to existing widget`: Instantly syncs the selected skin preset to the user's active profile widget without requiring any game credentials or manual scrolling.
    - `Update widget content`: Pushes updated layout, hero art, and card text to the Discord application.
    - `Refresh widget stats`: One-click live stat refresh for Valorant and Fortnite cards.
    - `Publish static skin for vanilla Discord`: Generates and publishes the static composite hero image so vanilla Discord viewers see a themed card.
    - `Create my widget`: One-click widget creation when a widget is not yet linked.
  - Eliminated the need to scroll past 20+ form fields to reach the primary action buttons while preserving the bottom action controls inside `WidgetEditor`.

- **Crash-Proof Store Access & Resilient Settings Loading**:
  - Implemented `safeStore()` and `setSetting()` helpers in `plugins/DMWidget/index.tsx` to safely access and mutate Vencord PlainSettings.
  - Replaced all unprotected `(settings.store as any)` property reads throughout `getEffectiveRiotId`, `getEffectiveFnIgn`, `heroUrlFor`, `presetHeroUrl`, `fortniteStatLines`, `slotHeader`, `syncFortniteRankIcon`, `buildSurfaces`, `exportConfig`, `importConfig`, `selectedWidgetPreset`, `surfaceSkinMode`, and `selectedSurfacePreset` with safe fallbacks that never throw when settings are uninitialized or in the temporal dead zone.
  - Wrapped `settings.use(...)` in a `try/catch` fallback so any store hydration delay degrades gracefully to `safeStore()` rather than crashing the component.
  - Guarded `useResolvedPreview`, `ImgPreview`, and `PreviewImage` against `undefined` or non-string URLs, preventing unhandled `TypeError` exceptions during image resolution.

- **Modal Dimensions & Smooth Scroll Clearance**:
  - Expanded `PluginModal` to `ModalSize.LARGE` for `DMWidget` (and `DMCursor`), providing a wide, spacious viewport that comfortably fits the showroom grid and live previews.
  - Added 48px bottom padding to `.vc-settings-modal-content` in both `PluginModal.tsx` and `PluginModal.css` so the modal content and action buttons smoothly scroll to the bottom without getting clipped by the viewport boundary.
  - Replaced `<ErrorBoundary noop>` with `<ErrorBoundary message="...">` in `renderSettings()` to ensure any option rendering issue displays a helpful diagnostic card instead of silently swallowing the component.
  - Registered `settingsAboutComponent: WidgetStylePicker` in `definePlugin({ ... })` so Vencord renders the showroom natively above Settings, and removed the duplicate `stylePicker` setting from `settings.def`.
