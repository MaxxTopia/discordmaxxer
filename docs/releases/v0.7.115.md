# Discordmaxxer v0.7.115

## Highlights

- Tournament Mode now owns the reduced-cost visual path: optional animation
  clocks, profile finish effects, widget decoration, video backgrounds, and
  third-party animation timers pause together, while voice, media playback,
  capture, and screenshare remain protected.
- Normal mode keeps the full visual presentation available for users who want
  animated widget skins, profile flair, themes, and plugin effects.
- Profile Flair now aligns with the shared profile-media service: free profile
  activation can publish owned banner/avatar media and exact profile colors,
  while tier controls add optional crop, fit, scale, speed, and effects.
- Profile and plugin status changes use visible in-client toasts instead of a
  grey-dot-only indication.

## Fixed

- Preserved widget-skin ownership across profile cards and other users' popouts
  instead of borrowing the viewer's local skin.
- Kept animated banner/avatar and profile presentation state stable during
  refreshes and cross-client loading.
- Preserved the native audio path and its loopback verification while applying
  the performance changes.

## Release boundary

This release has passed the source, type/build, strict overlay, plugin,
packaging, and local packaged-client smoke gates. It does not claim a new
scientific benchmark proving that Discordmaxxer is lighter than stock Discord;
that comparison remains a post-update test on the user's two PCs. Voice and
screenshare quality also require real-device acceptance after updating.
