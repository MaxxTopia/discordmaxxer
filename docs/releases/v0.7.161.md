# Discordmaxxer v0.7.161

## Highlights

This maintenance release keeps Discordmaxxer's branded startup surface visible
until Discord is ready, removing the generic loading shell and desktop bleed
that could appear during a slow renderer start.

## Fixed

- Keep the opaque Discordmaxxer splash above the renderer during startup and
  navigation transitions.
- Prevent the desktop and Discord's generic `Opening Discord App.` surface
  from appearing behind the splash.
- Require consecutive healthy renderer observations before dismissing startup
  recovery, while preserving bounded startup recovery for a genuinely stalled
  renderer.

## Verification

The release is gated by the strict Vencord overlay build, artifact-integrity
verification, application build, Windows packaging, and the documented
renderer validation checks. An isolated Windows smoke launch showed only the
Discordmaxxer splash during startup before reaching Discord's login surface.
Signed-in account, Tournament Mode, and remote-outage behavior remain device-
side checks after updating.
