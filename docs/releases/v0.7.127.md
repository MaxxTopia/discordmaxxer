# Discordmaxxer v0.7.127

## Native Discord interaction stability

This release keeps Discord's native message and image context-menu routes authoritative. Custom message-menu injections that could crash normal text or image interactions were removed, while the existing hover image controls and plugin settings remain available.

## Highlights

- Normal text and image messages retain Discord's native Reply, Forward, reactions, Pin, Bookmark, Copy Message Link, and related actions.
- Full-screen image interactions no longer receive a competing custom context-menu route from the overlay.
- DMEmoji's composer send control no longer matches Gift or Nitro controls, and it can attach an imported/custom emoji image in a direct message instead of sending unsupported custom-emoji markup.
- Widget motion no longer pauses merely because the window focus moved; tournament mode, hidden-document, offscreen, and reduced-motion safeguards remain active.
- Display-name styling uses broader profile/self selectors and preserves the selected gradient with stronger CSS ownership.
- Existing profile flair, widget-skin, theme, tournament-mode, media, and optimization work remains included.

## Verification

- ESLint and TypeScript checks pass with `pnpm test`.
- The strict Vencord overlay, staged-source verifier, production build, directory package, and Windows package gates pass before publication.
- After updating, a signed-in user should verify animated widget skins, display names, the DMEmoji attachment/send path, ordinary text and image context menus, full-screen image right-click behavior, and existing profile/plugin surfaces.
