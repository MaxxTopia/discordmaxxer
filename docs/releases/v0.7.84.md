# Discordmaxxer v0.7.84

This is attempt #6 at making existing-widget skins render consistently across
the full profile Board, compact profile popout, and Discordmaxxer Playing card.

## What's changed

- Widget skins now resolve to the actual application card instead of a profile,
  banner, avatar, gradient, or multi-card list wrapper.
- Full Board cards with Discord's camel-case class names are detected reliably,
  while ambiguous wrappers stay unskinned rather than leaking a skin across the
  profile.
- The Discordmaxxer Playing card follows the selected visible widget treatment
  without styling unrelated activity cards.
- Skin recovery replaces a stale startup scan so an existing widget updates
  promptly after recovery or an account switch.
- Fortnite widget stat copy now says **Current Rank** instead of **Highest
  Rank**; the stored stat field remains compatible with existing widgets.

The dev-client flow was tested end to end: a recovered existing Valorant widget
changed skins without re-entering private game credentials, persisted after a
clean relaunch, and left the profile banner, avatar, and gradient untouched.

Widget skins remain Discordmaxxer-rendered presentation. They do not become
native Discord widget fields, so vanilla Discord users still see the published
widget card without these client-only effects.
