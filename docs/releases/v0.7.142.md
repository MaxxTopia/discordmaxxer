# Discordmaxxer v0.7.142

## Highlights

- **Fix App Theme Leaking / Fullscreen Scaling**:
  - Bound profile container scans strictly to valid profile popout/dialog roots; prevented ancestor climbing to `#app-mount`.
  - Added `cleanUpLeakedRootThemes()` to scrub any residual gradients from `#app-mount`, body, and app layers on startup and during scans.
  - Removed bootstrap flex constraints on `#app-mount` and cleaned up display defaults once Discord mounts, resolving fullscreen letterboxing and DM message image sizing.

- **Profile Popout Visual & Legibility Fixes**:
  - Added transparency rules for `.footer_`, `.footer__`, `footer`, and `.viewFullProfile` so the profile gradient flows seamlessly without a black box.
  - Enforced crisp white text fill and drop shadow for username, display name, and tag elements on custom profile gradients.
  - Excluded channel/chat header titles from name styling to ensure top-bar title pills stay bright white.
  - Added DM channel recipient fallback and Diggy identity fast-paths so popout avatars and banners load on frame 0 with zero delay.

- **Widget Skin Persistence & Editor Restored**:
  - Maintained local style fallbacks when viewing Diggy accounts so Fortnite and Valorant widget skins never drop while remote markers hydrate.
  - Restored interactive Widget Skin selection grid directly inside `WidgetEditor` above the action buttons.
  - Fixed hotkey character validation in `DMVoiceKeybinds` so keys containing "s" (such as `ctrl+alt+s`) save cleanly and persist to localStorage permanently.
