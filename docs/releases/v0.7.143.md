# Discordmaxxer v0.7.143

## Highlights

- **DMCursor Smoothness & Input Latency Elimination**:
  - Eliminated the universal CSS selector `html.anime-cursor-active *` which was causing full-DOM style recalculations across all ~10,000 elements on every mouse movement and hover.
  - Scoped `cursor: none !important` exclusively to interactive elements (`a, button, input, textarea, select, [role="button"], [role="tab"], [role="link"], [role="menuitem"], [role="treeitem"], [class*="clickable" i], [class*="button" i], [class*="interactive" i], [class*="item" i], [class*="link" i]`).
  - Switched pointer positioning from compound percentage transforms (`translate3d(...) translate(-50%, -50%)`) to direct pixel GPU compositor translation (`translate3d(${lastX - 22}px, ${lastY - 22}px, 0)`), bypassing percentage matrix recalculations.
  - Replaced the delayed `requestAnimationFrame` render queue with instantaneous zero-latency transform updates in `mousemoveHandler`, eliminating up to 16ms of input lag and making the cursor feel instant and responsive at 144Hz–240Hz+ gaming refresh rates.
  - Throttled `kickActivity()` timer clearing so `clearTimeout`/`setTimeout` only runs at most twice a second instead of 1,000 times per second during mouse motion.
  - Guarded `setIdle()` with an `isCurrentlyIdle` check to prevent dirtying the element's `classList` when idle state has not changed.
  - Guarded pointer visibility writes with a boolean `cursorVisible` check, avoiding redundant style writes.
  - Capped active Stiiizy smoke particle DOM count to 16 nodes to eliminate compositor layer proliferation during rapid cursor sweeps.

- **Benchmark & Optimization Verification**:
  - Verified all core optimizations from v0.7.113 and v0.7.114 remain active and intact:
    - WebRTC Opus audio and NetEq jitter buffers permanently shielded at `PRIORITY_NORMAL`.
    - Universal voice call detection for 1-on-1 DMs, Group DMs, and voice servers.
    - Chromium background timer throttling protection during active voice calls and screenshares.
    - Pure GPU compositor keyframes for anime cursor skins without CPU SMIL recalculations.
    - Idle/focus animation freezes pausing cosmetic loops when unfocused or stationary.
  - Benchmarked current Discordmaxxer against Stock Discord and historical 2026-10-31 benchmarks:
    - Current Discordmaxxer maintains a flat, leak-free memory curve (1519 MB working set, -1.9 MB drift over 60s), resolving the old 2026-10-31 Smart Visuals memory climb (+858 MB).
