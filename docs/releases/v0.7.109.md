# Discordmaxxer v0.7.109

## Highlights

Comprehensive rewrite and overhaul of DMTranslate with universal language auto-detection (Japanese, Spanish, Russian, Chinese, German, Korean, Arabic, etc.), multi-engine fallback architecture (Google Translate Single, Google PA, MyMemory, and DeepL API), inline message accessories with quick copy/dismiss, and modern stable modal translation dialogs.

## What's New & Fixed

- **Universal Auto-Detection & Multi-Engine Pipeline**:
  - Automatically detects any source language from right-clicked messages and translates it into English (or user-chosen target language).
  - Integrated resilient multi-engine translation chain: primary Google Translate single endpoint with automatic failover to Google PA, MyMemory, and optional DeepL API.
  - Zero external Python, server helper, or API key requirement for standard instant translations.
- **Modern UI & Dual Translation Presentation**:
  - Replaced broken `Alerts.show` with Discordmaxxer's stable `ModalRoot` / `ModalHeader` / `ModalContent` / `ModalCloseButton` modal architecture wrapped in an `ErrorBoundary`.
  - Added native inline translation accessories (`renderMessageAccessory`) underneath messages displaying source language, translated text, and quick `Copy` / `Dismiss` buttons.
  - Added dedicated copy-to-clipboard action buttons for both original text and translated output in the translation modal.
- **Build Verification**:
  - Added `DMTranslate` to `REQUIRED_PLUGINS` in `overlay-scripts/verify-build.mjs` ensuring bundle inclusion on every production build.
