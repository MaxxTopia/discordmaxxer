# Discordmaxxer v0.7.121

## Highlights

- Fixed the detached DMCursor marker that could remain visible as a purple dot after calls, navigation, reloads, or renderer visibility changes. The cursor layer now hides until a real pointer movement makes it relevant again.
- Hardened image context-menu integration so Discord's native image menu remains intact instead of crashing while custom image actions are added. Reply, Forward, Pin, Bookmark, Reminder, Apps, Mark Unread, Copy Message Link, and reactions remain native actions.
- Kept the image attachment click path native so received images can open in Discordmaxxer's enlarged viewer normally.
- Improved DMTrim's bounded sponsored-card handling, DMEmoji's mouse-send and custom emoji discovery, DMProfileCosmetics' native-gradient default, and the compact plugin authors presentation.
- Included the updater's low-disk guard so a full Windows temporary volume produces a clear retry message instead of a misleading installer failure.

## Verification

- Strict pinned Vencord overlay, TypeScript/lint tests, renderer build verification, Windows packaging, and isolated packaged startup smoke were run for this release candidate.
- Signed-in image context-menu behavior, image enlargement, calls, and other account-specific interaction remain final user acceptance checks.
