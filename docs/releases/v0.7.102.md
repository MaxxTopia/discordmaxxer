# Discordmaxxer v0.7.102

## Highlights

This patch restores stable animated-avatar rendering while a shared profile
roster is loading or refreshing.

## Fixed

- Fixed a startup and refresh regression that could replace an owner's saved
  animated avatar with the default avatar before the shared profile state was
  ready.
- Kept the last known good owner avatar visible during roster hydration, while
  still honoring an explicit cloud-side avatar clear once that state is known.
- Kept the repair scoped to avatar rendering; banners, widget skins, profile
  colors, and account ownership resolution are unchanged by this patch.

## Notes

- This release fixes the Discordmaxxer client-side avatar regression. It does
  not make Discordmaxxer-only profile media native to vanilla Discord.
- After installing, fully quit and relaunch Discordmaxxer before testing an
  animated avatar on another Discordmaxxer installation.
