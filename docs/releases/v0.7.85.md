# Discordmaxxer v0.7.85

This is attempt #7 at making existing-widget skins apply to the visible Board
card without leaking onto the profile banner, avatar, gradient, or unrelated
activity cards.

## What's changed

- Existing widget skins now resolve semantic `article`/`listitem` Board cards
  as well as Discord's hashed and camel-case card classes.
- Remote skin-marker writes are read back before Discordmaxxer reports that
  cross-install recovery succeeded.
- Stale wrapper markers are cleared without removing the skin from a real
  widget card, and the Discordmaxxer Playing card keeps following the selected
  widget treatment.
- Fortnite widgets now use the same live-stat schedule as Valorant: one
  refresh shortly after startup and another every 30 minutes while
  Discordmaxxer is open, when the Epic IGN, public career stats, and API key
  are configured.
- Fortnite's first published stat is labeled **Current Rank** instead of
  **Highest Rank**; the stored rank field remains compatible with existing
  widgets.

Skin-only application still changes Discordmaxxer presentation without
  republishing the native Discord card. Use the explicit content update or
  stats refresh action when the published Fortnite card itself needs the new
  label or fresh values. Vanilla Discord receives the supported widget payload,
  not Discordmaxxer-only skin effects.
